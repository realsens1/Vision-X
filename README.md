# Vision X

Universal script

## Loadstring

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/realsens1/Vision-X/refs/heads/main/VisionX.lua"))()
```

## Features

- Player tools: Click TP, Sit, Fling Guard
- Tap a player's name to Teleport, Spectate or Follow
- Freecam with speed slider and UP/DOWN buttons
- Infinity Camera
- Server tools including Anti-AFK
- Murder Mystery 2 tab: Role ESP with a role filter, teleport to murderer or sheriff, Auto Grab Gun, Dodge Sword
- Customize: themes, transparency, position lock, toggle key
- Favorites, Search and a built-in Changelog

## Notes

- Works best on mobile executors, but also runs on PC
